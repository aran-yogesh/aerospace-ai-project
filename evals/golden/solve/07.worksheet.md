## Segment 0, riser pipe, D 16 mm, L 0.15 m

- e/D = 1.524e-6 / 0.016 = 9.525e-5
- Churchill: A_c = 4.97048e19, B_c = (37530/15890.1)^16 = 9.37605e5, f = 0.0276083

## Segment 1, 90 deg bend, r/d 2, D 16 mm (Crane p. A-29)

- f_T = 0.25 / [log10((9.525e-5)/3.7)]^2 = 0.25 / (-4.58934)^2 = 0.0118697

## Segment 2, ball valve, Cv 6, referenced to the upstream ID 16 mm (Crane p. 2-10)

## Segment 3, gradual contraction 16 -> 10 mm (Crane p. A-26, formula 1)

- half angle 5.71059 deg, theta = 11.4212 deg (<= 45, so formula 1)
- sin(theta/2) = 0.0995037
- K (smaller diameter) = 0.8 sin(theta/2)(1 - beta^2) = 0.8 x 0.0995037 x 0.609375 = 0.0485081
- dp = K q(10 mm) = 0.0485081 x 3248.10 = **157.559 Pa**

## Appendix: scratch calculation

```python
from math import log, log10, pi, sin
rho, mu, e = 998.2065434976523, 0.0010015965513039892, 1.524e-6

def state(D, m):
    v = m / (rho * pi * D * D / 4)
    return v, rho * v * D / mu, rho * v * v / 2

def churchill(Re, rr):
    A = (2.457 * log(1 / ((7 / Re) ** 0.9 + 0.27 * rr))) ** 16
    B = (37530 / Re) ** 16
    return 8 * ((8 / Re) ** 12 + (A + B) ** -1.5) ** (1 / 12)

def pipe(D, L, m):
    v, Re, q = state(D, m)
    return churchill(Re, e / D) * L / D * q

fT = lambda D: 0.25 / log10(e / D / 3.7) ** 2
m = 0.2
q16, q10 = state(0.016, m)[2], state(0.010, m)[2]
dps = [
    pipe(0.016, 0.15, m),
    12 * fT(0.016) * q16,
    891 * (0.016 / 0.0254) ** 4 / 36 * q16,
    0.8 * sin(5.710593137499643 * pi / 180) * (1 - 0.625**2) * q10,
    0.5 * 12 * fT(0.010) * q10,
    pipe(0.010, 0.2, m),
]
print(dps, sum(dps))
```
