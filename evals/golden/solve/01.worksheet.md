## Pipe (Darcy-Weisbach, Churchill f)

1. Area A = pi D^2 / 4 = pi (0.012)^2 / 4 = 1.13097e-4 m^2
2. Velocity v = mdot / (rho A) = 0.1 / (998.2065 x 1.13097e-4) = 0.885783 m/s
3. Reynolds Re = rho v D / mu = 998.2065 x 0.885783 x 0.012 / 1.001597e-3 = 10593.4 (turbulent, > 4000)
4. Dynamic pressure q = rho v^2 / 2 = 998.2065 x 0.885783^2 / 2 = 391.602 Pa
5. e/D = 1.524e-6 / 0.012 = 1.27e-4
6. Churchill (1977):
   - A_c = [2.457 ln(1 / ((7/Re)^0.9 + 0.27 e/D))]^16 = 2.10124e19
   - B_c = (37530 / Re)^16 = 6.15857e8
   - (8/Re)^12 = 4.4e-37, negligible
   - f = 8 [(8/Re)^12 + (A_c + B_c)^-1.5]^(1/12) = 0.0307454
   - Sanity check: Blasius 0.316 Re^-0.25 = 0.0312 (smooth pipe), within 1.5 %.
7. dp = f (L/D) q = 0.0307454 x (0.5 / 0.012) x 391.602 = **501.665 Pa**
