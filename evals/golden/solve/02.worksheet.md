# 02_bend_90: hand worksheet

Status: pending review by Rohith

Case file: `02_bend_90.solve.json`. Geometry: `../02_bend_90.expected.json`: pipe 200 mm, 90 deg
bend R 24 mm (r/d 2), pipe 200 mm, all ID 12 mm. Numbers come from a stand-alone scratch
calculation (plain `math`, no solver code), rounded to 6 significant figures.

## Inputs

Same fluid and material as case 01: rho 998.2065 kg/m^3, mu 1.001597e-3 Pa s (CoolProp 8.0.0,
Water 293.15 K, 1 bar), e 1.524e-6 m (stainless drawn). mdot 0.1 kg/s. No K overrides (the bend K
is computed).

## Flow state (same in all three segments, D 12 mm)

- A = pi (0.012)^2 / 4 = 1.13097e-4 m^2
- v = 0.1 / (998.2065 x 1.13097e-4) = 0.885783 m/s
- Re = 998.2065 x 0.885783 x 0.012 / 1.001597e-3 = 10593.4 (turbulent)
- q = rho v^2 / 2 = 391.602 Pa

## Segment 0, inlet pipe, L 0.2 m

- Churchill f at Re 10593.4, e/D 1.27e-4: f = 0.0307454 (steps as in worksheet 01)
- dp = f (L/D) q = 0.0307454 x (0.2 / 0.012) x 391.602 = **200.666 Pa**

## Segment 1, 90 deg bend, r/d 2 (Crane TP-410 p. A-29)

1. f_T, fully turbulent (von Karman), Crane p. A-26 method with this pipe's e/D:
   1/sqrt(f_T) = -2 log10((e/D) / 3.7) = -2 log10(1.27e-4 / 3.7) = -2 x (-4.46440) = 8.92880
   f_T = 1 / 8.92880^2 = 0.0125434
2. (L/D)eq for r/d 2 from Crane's bend table = 12
3. K90 = f_T x 12 = 0.150520; angle is exactly 90 deg so K = K90 = 0.150520
4. dp = K q = 0.150520 x 391.602 = **58.9441 Pa**

The bend's arc length (37.7 mm) counts on the plot x axis, but no extra Darcy friction is added:
Crane's (L/D)eq already includes it.
